# 决策天平 · 保研 / 考研 / 留学 / 就业 四赛道模拟器

> 输入 13 项个人参数，得到四条赛道的**概率区间、成本对比、6 个月行动清单与最坏情况预案**——**并列四条，不给唯一结论**。

## 1. 这是什么

面向大三 / 大四学生的**升学与就业决策模拟器**。它的定位不是「帮你做决定」，而是把决定背后的**四笔账**摊开给你看：

| 模块 | 内容 |
|---|---|
| ① 四条赛道的成功概率区间 | 保研 / 考研 / 留学 / 就业，各给区间与中值 |
| ② 成本横向对比 | 金钱成本、时间成本、机会成本 |
| ③ 权重滑块 | 五维权重随你拖动，排序实时变化 |
| ④ 选中赛道 · 未来 6 个月关键动作 | 5 条可执行清单 |
| ⑤ 最坏情况预案 | 每条赛道各自的退路 |
| ⑥ 模型假设与样本来源 | **不可关闭的常驻披露** |

### 当前版本的性质

- 单文件纯前端，双击 `index.html` 即可运行，**不含任何外部网络请求**；
- 参数与权重保存在浏览器 **localStorage** 中；
- 概率为**同类画像人群中的条件频率**，不是对个人的因果预测，**取整到 5 个百分点**（刻意不做更细的区分，避免虚假精确）；
- 区间为约 80% 置信带的**工程近似**，非严格贝叶斯后验。

## 4. 默认画像与默认权重

**默认画像**：GPA 3.4（4.0 制）/ 专业排名前 20% / CET-6 425–480 / 参与课题组（无论文）/ 校级竞赛奖 / 无实习 / 家庭预算 25 万 / 可投入备考 6 个月 / 风险偏好中性 / 新一线 / 目标同档院校 / gap 年看情况 / 行业景气平稳。

**默认权重**：成功概率 40%、金钱成本 20%、时间成本 15%、机会成本 15%、风险匹配 10%。

## 5. 四条赛道明细

| 赛道 | 成功概率区间 | 中值 | 推迟一年 | 置信度 |
|---|---|---|---|---|
| 保研 | 35%–45% | 40% | 20%–30%（−15pp） | 高（n≈12,400，客观公示） |
| 考研 | 25%–45% | 35% | 30%–50%（+6pp） | 中（n≈860，自报告） |
| 留学 | 25%–45% | 35% | 30%–50%（+4pp） | 低（n≈860，选择偏差大） |
| 就业 | 35%–50% | 43% | 40%–55%（+3pp） | 中（n≈860 + 校招 n≈310） |

### 「如果推迟一年」的对照规则

| 赛道 | 概率 | 时间 | 金钱 | 机会成本 | 原因 |
|---|---|---|---|---|---|
| 保研 | −15pp | +6 月 | +3 万 | +6 万 | 推免资格与应届身份绑定，延后通常失去排队位次 |
| 考研 | +6pp | +12 月 | +2 万 | +10 万 | 多一年备考；样本显示二战上岸率高于一战约 6pp（该样本选择偏差明显） |
| 留学 | +4pp | +12 月 | +3 万 | +10 万 | 可补语言与科研；学费按年涨约 5% 计 |
| 就业 | +3pp | +6 月 | +1 万 | +8 万 | 多一段实习可提升 offer 率，代价是少一年工龄 |

## 6. 模型假设与样本来源（常驻披露）

- **模型**：加权线性打分 → 区间映射（各因子独立可加，**未建模交互项与时序效应**）。
- **概率含义**：在同类画像人群中的条件频率，**不是对个人的因果预测**，也不含努力程度的因果回报。
- **样本来源**：
  - 保研：42 所高校 2022–2024 推免名额公示，n≈12,400（客观记录，偏差最小）
  - 考研：研招网与院校公开报录比 + 咨询队列 n≈860（自报告）
  - 留学：咨询队列 n≈860 + 院校公开录取区间（画像透明度低）
  - 就业：咨询队列 n≈860 + 校招 offer 统计 n≈310（行业周期敏感）
- **已知偏差与未建模项**：
  - 咨询队列为自报告样本，存在**选择偏差与幸存者偏差**（胜者更可能回填数据）
  - 样本以理工科与经管类为主，人文 / 艺术 / 医学外推可靠性较低
  - 未建模：政策突变、家庭变故、健康事件等尾部风险（**黑天鹅不进区间**）
  - 同名「成功」在四条赛道定义不同：保研=取得名额，考研=被录取，留学=拿到任一 offer，就业=拿到可接受 offer

---

## 7. 硬约束（设计红线）

1. **不输出「你应当选择某条赛道」的唯一结论** —— 四条并列，权重由用户自己拖；
2. **不采集手机号、姓名、学校等身份信息**；
3. **不对未达成结果作人格评价**；
4. **模型假设与样本来源常驻披露，不可折叠、不可关闭**；
5. **概率取整到 5 个百分点** —— 刻意不做更细区分。

## 9. 已知限制

- 概率为群体条件频率，不构成对个人的预测或承诺；
- 样本以理工科与经管类为主，其他学科外推可靠性较低；
- 未建模尾部风险（政策突变、家庭变故、健康事件）；
- 权重滑块为线性加权，未建模因子间的交互作用。
